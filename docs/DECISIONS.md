# DECISIONS — Jewar Trust Demo (V1)

| ----- | ---------- | ---------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |

| D-002 | 2026-11-13 | All commits/pushes under Sam's GitHub name. No Claude co-author, attribution or collaborator.                                            | Sam owns the work. Enforced by `.claude/settings.json` + Lefthook.                                                        |
| D-003 | 2026-11-13 | Only approved tools; nothing added without approval.                                                                                     | Keep the demo lean and controlled.                                                                                        |
| D-004 | 2026-11-14 | Purpose: client demo. One product: Everyday Basmati Rice. Single scroll page.                                                            | Show the redesign idea quickly.                                                                                           |
| D-005 | 2026-11-14 | No version-upgrade plan for now.                                                                                                         | It's a demo.                                                                                                              |
| D-006 | 2026-11-14 | Buttons (Add to Cart / Buy Now) are visual only; show a "demo" toast.                                                                    | No shop backend in a demo.                                                                                                |
| D-007 | 2026-11-14 | Trust badge: Option 2 (oval stamp).                                                                                                      | Compact; works on the pack and as a web icon.                                                                             |
| D-008 | 2026-11-14 | Colours = exact pack values: cream `#FDF8F4`, green `#094233`, red `#B22C37`, plus rice `#E8D9B5`.                                       | Match the real pack.                                                                                                      |
| D-009 | 2026-11-14 | Audience: health-minded urban Indian families; mobile-first.                                                                             | Matches current site (₹, COD, all-India delivery).                                                                        |
| D-010 | 2026-11-14 | Never call Everyday Basmati "organic".                                                                                                   | Pack doesn't say so; only Premium rice is organic.                                                                        |
| D-011 | 2026-11-14 | Hosting: GitHub Pages, static only. Repo `Jewar-Trust-Project`; Vite `base` = `/Jewar-Trust-Project/`.                                   | Pages serves the site from a sub-folder named after the repo; without the matching base, files 404 and the page is blank. |
| D-012 | 2026-11-14 | Toolkit trimmed to frontend + 3D + quality (see CLAUDE.md). Removed all backend, routing, forms, data-fetching, analytics, Docker tools. | Static one-page demo doesn't need them.                                                                                   |
| D-013 | 2026-11-14 | 3D pouch modelled in Blender via a headless Python script; compressed with gltf-transform; loaded with drei `useGLTF`. gltfjsx not used. | Better shape than hand-built three.js geometry; repeatable; no GPU needed.                                                |
| D-014 | 2026-11-14 | Back of pouch uses a concept texture built from front art + site facts.                                                                  | Client hasn't supplied back artwork. Flag in demo.                                                                        |
| D-015 | 2026-11-14 | Fonts: Fraunces (headings), Inter (body), self-hosted via @fontsource. Wordmark stays an image.                                          | Close to pack lettering; no external font calls.                                                                          |
| D-016 | 2026-11-14 | Six phases (0–5); deploy timing changed by D-026. | Catch GitHub Pages issues early (timing superseded by D-026). |
| D-017 | 2026-11-14 | Scroll: native scroll + sticky canvas + Motion `useScroll`; not drei `ScrollControls`.                                                   | Works better on phones and with normal page scroll.                                                                       |
| D-018 | 2026-11-14 | Two canvases (page + product card); page canvas paused while card is open.                                                               | Simpler code; saves battery/GPU.                                                                                          |
| D-019 | 2026-11-14 | Unconfirmed facts (origin, shelf life, cooking) marked TO CONFIRM and hidden.                                                            | Don't show invented facts to the client.                                                                                  |
| D-020 | 2026-11-14 | Fallbacks: reduced-motion list view; static pouch image if no WebGL.                                                                     | Accessibility and safety during the pitch.                                                                                |
| D-021 | 2026-11-14 | 5 kg price shown as a **placeholder** (₹780, MRP ₹1,120), flagged in code.                                                               | Keeps the size toggle working in the demo; replace with the real price later.                                             |
| D-022 | 2026-11-14 | Footer credit: "Demo by Swayam Bansal".                                                                                                  | Sam's request.                                                                                                            |
| D-023 | 2026-11-14 | Git branch renamed `master` → `main`.                                                                                                    | Deploy/CI workflows target `main`.                                                                                        |
| D-024 | 2026-11-14 | Use system `cwebp` for one-off PNG → WebP conversion of site images.                                                                     | SPEC needs `.webp` files; no extra npm package needed.                                                                    |
| D-025 | 2026-11-14 | Gitleaks staged scan is `gitleaks git --pre-commit --staged --redact` (v8.30.1; `protect` no longer exists). Biome ignores `*.md`.       | Matches installed version; stops Biome reformatting the docs.                                                             |
| D-026 | 2026-11-14 | Never use the `gh` CLI. All checks run locally (`just preview` + Playwright MCP). GitHub Pages deploy only in Phase 5; `deploy.yml` is manual (`workflow_dispatch`). Sam does all commits, pushes and GitHub settings. | Sam controls GitHub; no login needed; no live-site checks before the demo is ready. |
| D-027 | 2026-11-14 | Rice-window shine uses a small (128×207) roughness map (G channel), not a separate face-group material. Generated in `build_pouch.py`. | One material per panel, tiny file (300 B after WebP), works the same in three.js. |
| D-028 | 2026-11-14 | Added `@gltf-transform/cli` (approved) as a dev dependency. `sharp` installed fine with prebuilt binaries; pnpm only listed `lefthook` as an ignored build script (already the case), so `onlyBuiltDependencies` was not changed. | Needed for `just optimize`. |
| D-029 | 2026-11-14 | Pouch is one watertight mesh: front and back share vertices at the top and sides, open into a 9 cm boat-shaped gusset closed by a flat base. Real metres, origin bottom-centre, front faces +Z. Sizes are named constants at the top of `build_pouch.py`. | No gaps; stands upright; easy to tune. |
| D-030 | 2026-11-14 | `just optimize` runs gltf-transform with `--simplify false`. The full 8,710-triangle mesh ships. | Simplify cut the mesh to 4,375 triangles and could flatten the puff. The full mesh is still far under budget (479 KB, 8.7k tris). |
| D-031 | 2026-11-14 | Hero idle motion is a slow float plus a gentle sway (about ±24°), not a full spin. | The front label stays readable. Full turns are for the scroll story. |
| D-032 | 2026-11-14 | `r3f-perf` loads lazily and only when `import.meta.env.DEV` is true. | Keeps it out of the production bundle. |
| D-033 | 2026-11-14 | Lighting is procedural: drei `<Environment>` with `<Lightformer>`s. No HDR file, no CDN, no runtime downloads. Canvas is transparent with `NeutralToneMapping`. Model loads with `useGLTF(url, false, true)` (no Draco, Meshopt on). | Static demo must work offline from its own files; neutral tone mapping keeps the pack's red and cream true. |
| D-034 | 2026-11-14 | `pnpm-workspace.yaml` sets `allowBuilds: { lefthook: false }`. | pnpm 12 fails `install` on unreviewed build scripts (broke CI). Lefthook hooks are installed by `just setup`, so its postinstall is not needed. |
| D-035 | 2026-11-14 | The 3D canvas (`StoryCanvas`, `Pouch`, three, r3f, drei) is a lazy chunk (`React.lazy` in `Stage.tsx`). The Loader reads progress from the `ui` store; a `ProgressBridge` inside the 3D chunk copies drei's `useProgress` into it. Sizes (gzip): initial JS 132 KB, 3D chunk 280 KB, total 412 KB (was 403 KB in one file; budget 450 KB). | Text, wordmark and loader paint before three.js loads. No-WebGL users never download the 3D chunk. |
| D-036 | 2026-11-14 | Key light colour is `#FFF4E6` (was white). Environment lightformers, texture, material and tone mapping are unchanged. | Warms the paper toward the photo's cream without touching the art. |
| D-037 | 2026-11-14 | Story: one sticky canvas layer (`pointer-events: none`) shared by hero and story. The pouch turns to a set angle per step (0°, 40°, 140°, 0°, −40°), damped. Progress 0–0.85 = 5 steps (index clamped 0–4); 0.85–1 = pouch front + "Explore the product". Section height 400svh (tune after phone check). | Readable front at the badge step; touch-scroll never captured by the canvas. |
| D-038 | 2026-11-14 | Footer socials are text links (lucide-react v1 has no Facebook/Instagram icons; no new package). Button is a small hand-written shadcn-style `button.tsx` (cva), no Radix. | Stay inside the approved toolkit. |
